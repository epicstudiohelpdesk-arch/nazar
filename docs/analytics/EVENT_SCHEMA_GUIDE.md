# Nazar Event Schema & Envelope Guide

## 1. Canonical Event Envelope Specification

All analytics events ingested into Nazar MUST conform to the canonical JSON envelope structure:

```json
{
  "eventId": "019438fa-72a1-7000-8b1e-450f3e691234",
  "eventName": "interaction.like.created",
  "eventVersion": 1,
  "occurredAt": "2026-09-29T11:45:00.000Z",
  "receivedAt": "2026-09-29T11:45:00.210Z",
  "producer": "CLIENT",
  "actorUserId": "019438fa-7000-7000-8000-000000000001",
  "anonymousId": "anon_a819c927f83",
  "sessionId": "sess_9182371",
  "deviceId": "dev_pixel8_001",
  "platform": "ANDROID",
  "appVersion": "1.4.0",
  "properties": {
    "targetUserId": "019438fa-7000-7000-8000-000000000002",
    "source": "DISCOVERY",
    "position": 3
  },
  "context": {
    "networkType": "WIFI",
    "locale": "en-US",
    "countryCode": "US"
  },
  "privacyClass": "SENSITIVE_BEHAVIORAL"
}
```

---

## 2. Field Definitions & Constraints

| Field          | Type          | Required | Description & Constraints                                                                                                  |
| :------------- | :------------ | :------: | :------------------------------------------------------------------------------------------------------------------------- |
| `eventId`      | `UUIDv7`      |   Yes    | Globally unique event identifier. Generated by producer. Used for deduplication.                                           |
| `eventName`    | `String`      |   Yes    | Valid name registered in canonical taxonomy (e.g., `discovery.feed.viewed`).                                               |
| `eventVersion` | `Integer`     |   Yes    | Schema version. Current default is `1`. Must be $\ge 1$.                                                                   |
| `occurredAt`   | `ISO 8601`    |   Yes    | Client or server timestamp when event transpired. Skew bounded to $[-7\text{ days}, +15\text{ mins}]$.                     |
| `receivedAt`   | `ISO 8601`    |   Yes    | Timestamp when the API Gateway ingested the record. Server-assigned.                                                       |
| `producer`     | `Enum`        |   Yes    | Originating runtime environment: `CLIENT` or `SERVER`.                                                                     |
| `actorUserId`  | `UUIDv7`      | Optional | Authenticated user ID. Set by session auth binding; cannot be forged by clients.                                           |
| `anonymousId`  | `String`      | Optional | Stable client device identifier before user authenticates. Max 128 chars.                                                  |
| `sessionId`    | `String`      | Optional | Ephemeral client interaction session identifier. Max 128 chars.                                                            |
| `deviceId`     | `String`      | Optional | Hardware or installation instance ID. Max 128 chars.                                                                       |
| `platform`     | `Enum`        | Optional | Origin platform: `IOS`, `ANDROID`, `WEB`, `ADMIN_CONSOLE`, `BACKEND_WORKER`.                                               |
| `appVersion`   | `String`      | Optional | Semantic version of client bundle (e.g. `1.2.0`). Max 32 chars.                                                            |
| `properties`   | `JSON Object` |   Yes    | Event-specific analytical payload. Max 16 KB serialized size.                                                              |
| `context`      | `JSON Object` | Optional | Environmental attributes (locale, network, coarse location). Max 8 KB size.                                                |
| `privacyClass` | `Enum`        | Optional | Classified privacy tier (`PUBLIC`, `PSEUDONYMOUS`, `RESTRICTED_PII`, `SENSITIVE_BEHAVIORAL`). Defaults to taxonomy rating. |

---

## 3. Ingestion Payload Size Limits

1. **Batch Size**: Maximum 50 events per HTTP request to `/v1/analytics/events`.
2. **Payload Size**: Maximum 256 KB total HTTP request body size.
3. **Property Depth**: Objects deeper than 5 levels of nesting are rejected.
4. **Key Format**: All keys in `properties` and `context` must be `camelCase` or `snake_case` alphanumeric strings (max 64 characters).

---

## 4. Registering a New Event

To register an addition to the taxonomy:

1. **Define Contract**: Add the payload interface and schema in `packages/api-contracts/src/analytics/analytics-events.contract.ts`.
2. **Assign Authority & Privacy Class**: Add entry to `CANONICAL_EVENT_TAXONOMY` in `apps/api/src/modules/analytics/constants/analytics.constants.ts`.
3. **Register Validation**: Add Zod property schema in `packages/validation/src/analytics.ts`.
4. **Update Aggregation**: If the event contributes to DAU, conversion funnels, or business KPIs, register it in `AnalyticsAggregationService`.
