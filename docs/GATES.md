# Engineering Gates Roadmap

This platform is implemented strictly through sequential, audited engineering gates. Each gate requires complete implementation, testing, verification, documentation, and a dedicated git commit.

| Gate        | Title                                                    | Scope & Acceptance Criteria                                                                                                                                                                                     | Status        |
| :---------- | :------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ |
| **Gate 0**  | **Monorepo Foundation & Tooling**                        | Monorepo setup, pnpm workspace, Turbo, strict TS, shared contracts (`@nazar/contracts`) with RFC 9562 UUIDv7, cursor pagination, Zod domain schemas, Docker Compose infra (PostGIS, Redis, MinIO), CI pipeline. | **COMPLETED** |
| **Gate 1**  | **Backend Modular Core & Database Engine**               | NestJS application bootstrap, Drizzle ORM configuration with PostgreSQL + PostGIS, migrations runner, database seeders, structured logging, health checks, global exception filters.                            | _PENDING_     |
| **Gate 2**  | **Identity, Auth & Session Lifecycle**                   | Authoritative backend auth, phone OTP verification flow, rotating refresh sessions with device fingerprinting and family revocation, JWT access token guard, audit logging.                                     | _PENDING_     |
| **Gate 3**  | **User Profile, Media & Onboarding**                     | Profile schema, age restriction enforcement, presigned S3/R2 media upload, moderation pipeline status, location coordinate updates with PostGIS geometry.                                                       | _PENDING_     |
| **Gate 4**  | **Spatial Social Discovery Engine**                      | Candidate feed generation via PostGIS spatial queries, age/intent/distance filters, exclusion of interacted users, cursor pagination, Redis discovery cache.                                                    | _PENDING_     |
| **Gate 5**  | **Interactions, Idempotent Matching & Outbox**           | Swipes (like/pass/superlike), idempotency protection, reciprocal match detection with canonical user sorting, transactional outbox pattern.                                                                     | _PENDING_     |
| **Gate 6**  | **Real-Time Messaging & WebSockets**                     | WebSocket gateway, authenticated connection handshake, match authorization, real-time message exchange, typing indicators, read receipts, message history cursor query.                                         | _PENDING_     |
| **Gate 7**  | **Asynchronous Background Processing & Queues**          | BullMQ/Redis worker engine, outbox processor, push notification dispatcher (FCM/APNs), profile indexer, media cleanup.                                                                                          | _PENDING_     |
| **Gate 8**  | **Mobile Client Architecture & Auth UI**                 | Expo + React Native setup, Expo Router navigation, TanStack Query, Zustand store, shared contracts integration, Phone OTP auth screens.                                                                         | _PENDING_     |
| **Gate 9**  | **Mobile Discovery & Social Experience**                 | Swipeable card deck, profile detail sheet, discovery filters modal, match celebration modal, haptic feedback.                                                                                                   | _PENDING_     |
| **Gate 10** | **Mobile Real-Time Chat & Media Viewer**                 | Real-time chat screen, optimistic messaging updates, media viewer, typing status, push notification handling.                                                                                                   | _PENDING_     |
| **Gate 11** | **Security Hardening, Observability & E2E Verification** | Rate limiting guards, OpenTelemetry tracing, Sentry error tracking, full integration test suite, deployment dockerfiles.                                                                                        | _PENDING_     |
