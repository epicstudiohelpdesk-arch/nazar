# Engineering Gates Roadmap

This platform is implemented strictly through sequential, audited engineering gates. Each gate requires complete implementation, testing, verification, documentation, and a dedicated git commit.

| Gate        | Title                                                    | Scope & Acceptance Criteria                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Status        |
| :---------- | :------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ |
| **Gate 01** | **Monorepo, Toolchain & CI/CD Foundation**               | Monorepo setup, pnpm workspace, Turborepo, strict TypeScript, shared packages (`@platform/api-contracts`, `@platform/domain`, `@platform/config`, `@platform/ui`, `@platform/validation`), workers shells, admin shell, mobile shell, Docker compose infra, GitHub Actions CI.                                                                                                                                                                                                                                                                                              | **COMPLETED** |
| **Gate 02** | **Backend Foundation + API Contract**                    | Production NestJS bootstrap, AsyncLocalStorage request context & UUIDv7 tracing, structured JSON logging with redaction, canonical response envelopes (`ApiSuccessEnvelope`, `ApiPaginatedEnvelope`, `ApiFailureEnvelope`), global validation pipe with prototype pollution defense, global exception filter, idempotency subsystem (`@Idempotent`), rate limiting foundation, OpenAPI / Swagger documentation (`/docs`), health & readiness probes (`/health`, `/ready`, `/v1/health`, `/v1/ready`), decoupled infrastructure interfaces, future domain module boundaries. | **COMPLETED** |
| **Gate 03** | **Database Engine, Migrations & PostGIS Foundation**     | PostgreSQL 16 + PostGIS 3.4 integration, Drizzle ORM, connection pool configuration, programmatic migrations runner, development seeder and reset tooling, PostGIS SRID 4326 spherical geodesic distance calculation, durable PostgreSQL idempotency store, transaction & unit of work management, decoupled readiness probe.                                                                                                                                                                                                                                               | **COMPLETED** |
| **Gate 04** | **Identity, Auth & Session Lifecycle**                   | Authoritative backend auth, phone OTP verification flow, rotating refresh sessions with device fingerprinting and family revocation, JWT access token guard, audit logging.                                                                                                                                                                                                                                                                                                                                                                                                 | _NEXT_        |
| **Gate 05** | **User Profile, Media & Onboarding**                     | Profile schema, age restriction enforcement, presigned S3/R2 media upload, moderation pipeline status, location coordinate updates with PostGIS geometry.                                                                                                                                                                                                                                                                                                                                                                                                                   | _PENDING_     |
| **Gate 06** | **Spatial Social Discovery Engine**                      | Candidate feed generation via PostGIS spatial queries, age/intent/distance filters, exclusion of interacted users, cursor pagination, Redis discovery cache.                                                                                                                                                                                                                                                                                                                                                                                                                | _PENDING_     |
| **Gate 07** | **Interactions, Idempotent Matching & Outbox**           | Swipes (like/pass/superlike), idempotency protection, reciprocal match detection with canonical user sorting, transactional outbox pattern.                                                                                                                                                                                                                                                                                                                                                                                                                                 | _PENDING_     |
| **Gate 08** | **Real-Time Messaging & WebSockets**                     | WebSocket gateway, authenticated connection handshake, match authorization, real-time message exchange, typing indicators, read receipts, message history cursor query.                                                                                                                                                                                                                                                                                                                                                                                                     | _PENDING_     |
| **Gate 09** | **Asynchronous Background Processing & Queues**          | BullMQ/Redis worker engine, outbox processor, push notification dispatcher (FCM/APNs), profile indexer, media cleanup.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | _PENDING_     |
| **Gate 10** | **Mobile Client Architecture & Auth UI**                 | Expo + React Native setup, Expo Router navigation, TanStack Query, Zustand store, shared contracts integration, Phone OTP auth screens.                                                                                                                                                                                                                                                                                                                                                                                                                                     | _PENDING_     |
| **Gate 11** | **Mobile Discovery & Social Experience**                 | Swipeable card deck, profile detail sheet, discovery filters modal, match celebration modal, haptic feedback.                                                                                                                                                                                                                                                                                                                                                                                                                                                               | _PENDING_     |
| **Gate 12** | **Mobile Real-Time Chat & Media Viewer**                 | Real-time chat screen, optimistic messaging updates, media viewer, typing status, push notification handling.                                                                                                                                                                                                                                                                                                                                                                                                                                                               | _PENDING_     |
| **Gate 13** | **Security Hardening, Observability & E2E Verification** | Rate limiting guards, OpenTelemetry tracing, Sentry error tracking, full integration test suite, deployment dockerfiles.                                                                                                                                                                                                                                                                                                                                                                                                                                                    | _PENDING_     |
