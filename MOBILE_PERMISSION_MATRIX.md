# Nazar Mobile Application Permission Matrix

This document provides the authoritative permission audit for the Nazar mobile applications (Android & iOS). Permissions are restricted strictly to features actively supported by the platform. Superfluous permissions (e.g. background location, audio recording, address book scraping, Bluetooth) are strictly prohibited.

---

## 1. Declared Permissions Audit

| Permission Category          | Android Declaration                                       | iOS Declaration                                             | Why Required                                                                                                 | When Requested                                                | Denied / Graceful Degradation Behavior                                                                                         | Privacy & Protection Controls                                                                                                                             |
| :--------------------------- | :-------------------------------------------------------- | :---------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Location (Coarse & Fine)** | `ACCESS_COARSE_LOCATION`<br>`ACCESS_FINE_LOCATION`        | `NSLocationWhenInUseUsageDescription`                       | Spatial candidate discovery and matching to nearby dating profiles and community events.                     | Onboarding discovery setup or when opening Discovery tab.     | User can enter manual city/region preference; app functions without crashing; shows global or citywide profiles.               | Exact coordinates are truncated and protected via PostGIS SRID 4326. Exact lat/long is never exposed to other users. No background location is requested. |
| **Camera**                   | `CAMERA`                                                  | `NSCameraUsageDescription`                                  | Real-time photo capture for dating profile creation and verification.                                        | When user taps "Take Photo" in profile media grid.            | User cannot take new photos directly; can still select existing images from library or cancel.                                 | Camera is only activated when explicitly triggered by the user. Photos are processed via presigned URLs directly to secure storage.                       |
| **Photo Library**            | `READ_MEDIA_IMAGES`<br>`READ_EXTERNAL_STORAGE` (API < 33) | `NSPhotoLibraryUsageDescription`                            | Selecting existing photos to upload to dating profile.                                                       | When user taps "Choose from Library" in profile media editor. | User cannot upload new gallery photos; existing uploaded photos remain active.                                                 | Limited photo picker used where supported; app only reads media explicitly selected by the user.                                                          |
| **Push Notifications**       | `POST_NOTIFICATIONS` (API 33+)                            | Remote Notification Capability (`UNUserNotificationCenter`) | Real-time alerts for mutual matches, incoming chat messages, event reminders, and critical security notices. | Post-registration onboarding or first match creation.         | App functions completely; in-app badge updates and WebSocket real-time alerts still deliver notifications while app is active. | Redacted notification payloads: message previews can be disabled in Settings; tokens encrypted and revocable.                                             |

## 2. Explicitly Prohibited & Omitted Permissions

To maximize store compliance, security, and user trust, the following permissions are **explicitly prohibited** and confirmed absent from all production manifests:

| Permission                  | Android Identifier               | iOS Identifier                      | Reason for Omission                                                                                      |
| :-------------------------- | :------------------------------- | :---------------------------------- | :------------------------------------------------------------------------------------------------------- |
| **Background Location**     | `ACCESS_BACKGROUND_LOCATION`     | `UIBackgroundModes: location`       | Nazar matches based on last active discovery location; background tracking is unnecessary and intrusive. |
| **Microphone / Audio**      | `RECORD_AUDIO`                   | `NSMicrophoneUsageDescription`      | Voice notes and audio calls are not part of the active release candidate scope.                          |
| **Contacts / Address Book** | `READ_CONTACTS`                  | `NSContactsUsageDescription`        | Nazar does not perform address book scraping or contact-based discovery.                                 |
| **Bluetooth / Nearby**      | `BLUETOOTH`, `BLUETOOTH_CONNECT` | `NSBluetoothAlwaysUsageDescription` | Nazar uses server-side PostGIS spatial indexing, not peer-to-peer Bluetooth beaconing.                   |
| **External File Write**     | `WRITE_EXTERNAL_STORAGE`         | N/A                                 | App uses sandbox-scoped storage; global storage write permissions are obsolete and security risks.       |
